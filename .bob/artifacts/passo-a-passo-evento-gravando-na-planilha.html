📋 Evento gravando na Planilha do Google Sheets

Configuração da Cloud Function appendSheetEvent — projeto gj-santaterezinha

✦ Como funciona
ℹ
Quando você cria um evento no Painel Admin → aba Eventos, o app faz duas coisas ao mesmo tempo: salva no Firestore (aparece na agenda na hora) e chama a Cloud Function appendSheetEvent que grava uma nova linha na aba Eventos da planilha. Se a planilha falhar por qualquer motivo, o evento continua aparecendo normalmente.
1 Ativar a Google Sheets API no Cloud Console
  1. Acesse console.cloud.google.com e selecione o projeto gj-santaterezinha
  2. No menu lateral: APIs e Serviços → Biblioteca
  3. Pesquise por "Google Sheets API" e clique em Ativar
⚠
Se você já ativou a Google Calendar API anteriormente, o projeto e a chave já existem — só precisa ativar mais a Sheets API no mesmo projeto.
2 Criar (ou reusar) a Service Account
  1. Ainda no Cloud Console: IAM e administrador → Contas de serviço
  2. Se já existe uma conta de serviço para o projeto (pode ser a do Calendar), clique nela
  3. Se não existe: clique Criar conta de serviço, dê um nome (ex: agenda-gj) e clique Criar
  4. Na conta de serviço aberta: aba Chaves → Adicionar chave → Criar nova chave → JSON
  5. Clique Criar — o arquivo .json será baixado automaticamente
  6. Anote o campo "client_email" dentro desse JSON — você vai precisar no Passo 3
3 Compartilhar a planilha com a Service Account
  1. Abra sua planilha em sheets.google.com
  2. Clique em Compartilhar (botão verde no canto superior direito)
  3. No campo "Adicionar pessoas", cole o e-mail da service account (campo client_email do JSON) — ex: agenda-gj@gj-santaterezinha.iam.gserviceaccount.com
  4. Defina a permissão como Editor
  5. Clique em Enviar (pode aparecer aviso de "conta externa" — ignore e confirme)
✓
Este é o passo mais importante. Sem ele, a Cloud Function recebe erro 403 da planilha.
4 Configurar as variáveis de ambiente nas Functions

Abra o arquivo functions/.env (se não existir, copie de functions/.env.example) e adicione:

# Cole o conteúdo INTEIRO do JSON da service account, numa só linha:
GOOGLE_SERVICE_ACCOUNT_KEY={"type":"service_account","project_id":"gj-santaterezinha","private_key":"-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n","client_email":"agenda-gj@gj-santaterezinha.iam.gserviceaccount.com",...}

# ID da planilha — copie da URL da planilha:
# https://docs.google.com/spreadsheets/d/  ESTE_TRECHO  /edit
SHEETS_ID=1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms
⚠
O JSON deve estar em uma única linha. Se abrir o arquivo baixado, selecione tudo (Ctrl+A), copie e cole removendo as quebras de linha. Ferramentas online como jsonminifier.com fazem isso automaticamente.
5 Fazer deploy das Cloud Functions

No terminal, na raiz do projeto:

firebase deploy --only functions

Ou somente a função nova:

firebase deploy --only functions:appendSheetEvent

Aguarde o deploy terminar (aprox. 1–2 min). Você verá ✔ Deploy complete! ao final.

6 Verificar a estrutura da aba "Eventos" na planilha

A Cloud Function escreve exatamente nessa ordem de colunas (a partir da linha 5):

Col.CampoExemplo
ATítuloEncontro de Jovens
BCategoriajovens
CData2025-08-15
DHorário início19:30
EHorário fim21:00
FLocalSalão Paroquial
GDescriçãoVenha participar!
HURL da arte(vazio quando criado pelo painel)

ℹ
Linhas 1–4 são o cabeçalho (título, subtítulo, em branco, nomes das colunas). A função insere novos registros sempre a partir da primeira linha vazia, sem sobrescrever nada.
7 Testar
  1. Acesse a agenda, clique em Painel (logado como admin)
  2. Vá na aba Eventos → preencha o formulário → clique "Adicionar evento"
  3. O evento aparece na agenda imediatamente (via Firestore)
  4. Abra a planilha — uma nova linha deve ter aparecido na aba Eventos
⚠
Se a linha não aparecer na planilha mas o evento aparecer na agenda, abra o console do navegador (F12) e procure por mensagens [Agenda] Planilha não atualizada. Isso indica qual etapa ficou faltando (deploy, permissão ou variável de ambiente).
