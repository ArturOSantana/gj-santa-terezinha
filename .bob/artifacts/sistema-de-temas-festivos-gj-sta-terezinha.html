Sistema de Temas Festivos

Agenda dos Jovens · Paróquia Santa Terezinha do Menino Jesus · implementação completa

Como funciona

1
Datas litúrgicas hardcoded em theme.service.ts definem janelas de novena (9 dias antes) e festa para cada santo.
2
API de novenas (VITE_NOVENA_API_URL) é consultada — se confirmar uma novena ativa cujo slug esteja mapeado, um tema virtual complementar é criado automaticamente.
3
Firestore (agenda_themes) permite ao admin forçar ou ajustar qualquer tema em tempo real.
4
Conflito resolvido por: forçado > priority:true > mais próximo da festa. (ex: 12/out → Aparecida vence Carlo Acutis)
5
CSS Cascade — data-tema="slug" em .agenda-root ativa tokens --hero / --accent / --bg / --soft / --crest-bg do tema vencedor.

O que ativa automaticamente

A
Data do dispositivo — basta hoje cair na janela noveenaStart→endDate de qualquer tema. Sem configuração.
B
API de novenas — se VITE_NOVENA_API_URL estiver configurado e retornar um slug mapeado (ex: nossa-senhora-carmo), o tema mariano correspondente ativa mesmo que as datas hardcoded tenham leve divergência.
C
Admin no painel — qualquer admin pode forçar um tema manualmente a qualquer momento via Firestore, para festas especiais ou missões.
